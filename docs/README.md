# OnCue documentation

- [Architecture records](architecture/README.md): how each part of OnCue works, the decisions behind it, its limits, and what is not built yet. The records are the source of truth for the current design.

- [Roadmap](roadmap.md): planned work that is not built.
- [Backlog](backlog.md): known open defects and gaps, each with the code that shows it.
